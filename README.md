# Алгоритмы и анализ сложности — графы

Четыре отдельные программы на Java. Вершины нумеруются от `0` до `n - 1`.
Каждый `Main.java` запускается отдельно, без дополнительных библиотек.

## Запуск

Нужен JDK 8 или новее. Например, для первой задачи:

```text
cd task-1-4
javac -encoding UTF-8 Main.java
java Main
```

После запуска ввести данные из условия. Для остальных задач перейти в соответствующую папку.

## Задача 1.4. Распространение новости

Ввод: `n m s t`, затем `m` ориентированных рёбер `u v`.
Обход в ширину находит минимальное число пересылок. Массив `parent` нужен для восстановления пути.

Ввод из условия:

```text
5 5 0 4
0 1
0 2
1 3
2 3
3 4
```

Вывод:

```text
distances=0 1 1 2 3
distance=3 path=0 1 3 4
```

Первая строка содержит расстояния до всех вершин, как требует текст задания.
Для недостижимой цели вторая строка: `distance=-1 path=-1`.

## Задача 2.10. Большие расстояния

Ввод: `n m s t`, затем `m` рёбер `u v w` с неотрицательными весами.
Направленность в условии не указана: дороги считаются двусторонними.

Веса и расстояния хранятся в `long`: сумма двух дорог по `2000000000` равна
`4000000000`, что больше максимального значения `int` — `2147483647`.
Сложение выполняется над значениями `long`, поэтому переполнения `int` нет.

Ввод из условия:

```text
3 2 0 2
0 1 2000000000
1 2 2000000000
```

Вывод:

```text
distance=4000000000
```

Если пути нет, выводится `distance=-1`.

## Задача 3.3. Электросеть

Ввод: `n m`, затем `m` неориентированных рёбер `u v w`.
Рёбра рассматриваются по возрастанию стоимости. Ребро добавляется, если оно соединяет разные компоненты.
Равные веса могут давать разные остовы, но минимальная стоимость остаётся одинаковой.

Ввод из условия:

```text
5 7
0 1 1
0 2 1
1 2 1
1 3 2
2 4 2
3 4 2
0 4 10
```

Вывод:

```text
cost=6 edges=4
```

Если граф несвязный, общего остова нет. Для этого случая принят вывод `IMPOSSIBLE`,
поскольку отдельный формат ошибки в условии не задан.

## Задача 4.4. Установка пакетов

Ввод: `n m`, затем `m` дуг `dependency package`.
Зависимость должна стоять раньше соответствующего пакета.
Обход в глубину выполнен с явным стеком, чтобы длинная цепочка зависимостей не переполнила стек вызовов Java.

Ввод из условия:

```text
4 4
0 1
1 2
2 0
2 3
```

Вывод:

```text
CYCLE 0 1 2 0
```

Начальная вершина повторяется в конце, чтобы показать замыкание цикла.
Выводятся только вершины найденного цикла, без зависящих от него пакетов.
Если циклов нет, выводится допустимый порядок установки всех пакетов через пробел.
